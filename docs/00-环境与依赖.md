# 环境与依赖

## 1 本机实测

| 项 | 实测值 | 影响 |
|---|---|---|
| CPU | Intel Xeon E5-2673 v3，12 核 24 线程 @2.4 GHz，AVX2（无 AVX-512） | 单核性能一般，靠多进程扩展 |
| 内存 | 15.54 GiB（可用约 14 GiB），4 GiB swap | 单会话 <1 GiB；批处理 ≤16 进程 |
| 磁盘 | 1006.9 GiB，可用 928.5 GiB | 数据集可放下，但需保留策略 |
| GPU | 无，无 `/dev/dri` | 不训练深度模型；参考检测器用规则/GBDT |
| 权限 | 无 sudo（no-new-privileges），无 docker/conda | 仅能用 pip wheel |
| Python | 3.14.4，venv 正常 | 依赖需 cp314 wheel |
| SUMO | 1.28.0（`eclipse-sumo` wheel），`sumo/bin` 与 `sumo/tools` 可用 | 启动约 0.3–1 s |
| Web | FastAPI 0.162 + uvicorn 0.54 + SSE | 与仿真同进程，无外部服务 |

## 2 依赖安装

```bash
python3 -m venv .venv
.venv/bin/pip install -e ".[dev,dataset]"
```

`pyproject.toml` 中：

| 依赖 | 用途 |
|---|---|
| `eclipse-sumo` | SUMO 二进制与 `traci`/`sumolib`（wheel 内含，无需 root） |
| `numpy` | 随机数、数值计算 |
| `PyYAML` | 场景配置 |
| `fastapi` / `uvicorn` | Web 控制台 |
| `pyarrow`（可选） | Parquet 数据集 |
| `scikit-learn`（可选） | 参考检测器扩展 |
| `pytest`（可选） | 测试 |

SUMO 路径由 `isacsim/sumo_env.py` 自动定位：优先 `SUMO_HOME`，其次已安装的 `sumo` 包，再回退 `/usr/share/sumo` 等。启动时会设置 `SUMO_HOME`、`PATH` 与 `sys.path`，并校验版本。

## 3 路网资产

```
assets/nets/arterial/nodes.nod.xml
assets/nets/arterial/edges.edg.xml
assets/nets/arterial/net.net.xml      # netconvert 产物（提交到仓库）
assets/routes/arterial.rou.xml        # 车流
```

生成命令：

```bash
./scripts/build_net.sh
```

注意 `--offset.disable-normalization true`：否则 netconvert 会把路网平移到 (0,0)，导致传感器坐标与路网错位。

### 4.1 清理开发产物

`out/` 会随每次 Web 会话和批量实验持续增长。用 `clean` 子命令按保留策略清理：

```bash
# 1) 预览：默认只清 Web 会话，保留最近 3 个；不删除任何文件
.venv/bin/python -m isacsim clean

# 2) 确认后执行
.venv/bin/python -m isacsim clean --keep 3 --yes

# 3) 只清 7 天前的 Web 会话（仍保留最近 3 个）
.venv/bin/python -m isacsim clean --older-than 7 --yes

# 4) 同时清理批量/实验目录（谨慎：report/eval 会随目录一起删除）
.venv/bin/python -m isacsim clean --include-batches --keep 2 \
    --protect out/m6_500_500 --yes

# 5) 清空所选范围（仍保护正在写入的 Web 会话）
.venv/bin/python -m isacsim clean --all --yes
```

策略说明：

- 默认**只清 `out/web/` 下的 Web 会话**；`out/` 下的批量数据集、`nidd_*` 导出、日志和截图不会被默认删除。
- 批量/实验目录是**整目录**保留最近 N 个，不会只删其中几条运行，避免留下与 `report.md`/`eval.json` 不一致的数据。
- 正在运行的 Web 会话由 `out/web.pid` 识别并自动保护；也可用 `--protect PATH` 额外保护验收数据集。
- 不加 `--yes` 一律只预览。删除前建议先确认 `out/m6_500_500` 等验收证据已另行保存。

## 5 已知限制

- 无 GPU：不做时序深度模型训练；参考检测器为轻量规则 + 可选 GBDT。
- 无 root：不能 `apt install`，只能用 pip wheel；SUMO 通过 wheel 提供。
- 单机单会话：Web 控制台同时只跑一个仿真（多浏览器共享状态）。
- 浏览器在远程时：默认绑定 `127.0.0.1`，需 SSH 端口转发（见 Web 文档）。

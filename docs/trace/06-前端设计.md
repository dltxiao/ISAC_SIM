# 06 前端设计

## 1. 视觉定位

不是 IDA Pro 的仿制品，而是 **调试器式数据观察台**：

- 深色底、等宽数字、固定列宽、低饱和配色；
- 信息密度高，但每个区域只回答一个问题；
- 颜色只用于“变化/攻击/告警”，不用于装饰；
- 动画克制：变化高亮 600 ms 淡出，不闪烁。

参考的不是 IDA 的反汇编窗口，而是它的 **Debugger → Registers / Watch / Hex / Xrefs** 工作方式。

## 2. 页面结构

### 2.1 顶栏

- 会话状态、仿真时间、tick、模式（live/step/replay）；
- focus 攻击选择；
- 主要操作：冻结/继续、下一步（检查点）、下一步（tick）、跳到下一次攻击、导出；
- 连接状态/延迟/丢弃计数；
- 不要放“开始/停止/复位”全部控制，避免和主控制台重复；提供“回到主控制台”链接。

### 2.2 左栏：Watch 树

- 分组：Scene / Sensors / Vehicles / Network / Detection / Attacks / Truth；
- 每项显示：名称、当前摘要（如 `6 objects / 3 ghosts`）、状态点；
- 支持搜索、折叠、固定（pin）；
- 点击选中，中栏滚动到对应卡片；
- 攻击组显示 `ATK001`、阶段、t0/t1；
- 无攻击时 Attacks 组显示“无活动攻击”。

### 2.3 中栏：卡片/寄存器

每张卡片是一个 target：

```text
┌ RSU-01 · sensing.objects ────────────────────────── ▲ 10 Hz ─┐
│ t=3.10  seq=1842  frame=31  objects=6  ghosts=3  Δ +3       │
│ ┌ object_id ─ cls ─ x ─ y ─ entity ─ flag ─────────────────┐│
│ │ 1           car   205.0 -35.1 veh:eastbound.1  —         ││
│ │ 9000        car    41.5  -8.4 ghost:9000      NEW       ││
│ │ 9001        obstacle 50.5 -8.0 ghost:9001     NEW       ││
│ │ 9002        car    59.5  -7.6 ghost:9002      NEW       ││
│ └───────────────────────────────────────────────────────────┘│
│ [显示 4/6] [原始 JSON] [设为基线]                            │
└──────────────────────────────────────────────────────────────┘
```

卡片类型：

| 类型 | 形态 | 例子 |
|---|---|---|
| `scalar` | 大数字 + 单位 + sparkline | `net:pc5.cbr` |
| `struct` | 2–4 列 key/value | `atk:ATK001`、`veh:eastbound.2.state` |
| `table` | 表头 + 行 + diff 标记 | `sensor:*.objects`、`veh:fleet` |
| `event` | 事件列表 | `det:alerts` |
| `series` | 折线/面积 | CBR、速度、TTC |

卡片头部信息：

- target label、kind、rate；
- `t/seq`、`status`（new/changed/stale/error）；
- 摘要（count/ghost/alert）；
- 操作：pin、折叠、原始 JSON、设为基线。

变化标记：

- `NEW`：新增行/字段；
- `DEL`：删除；
- `Δ`：数值变化，显示 `before → after`；
- 行背景色只闪 600 ms；之后保留左侧色条；
- 颜色语义固定：灰=正常，琥珀=变化，红=攻击/告警，紫=真值。

### 2.4 右栏：Trace/Xref

两个 tab：

- **Trace**：按 seq 倒序的事件列表，支持按 kind/attack/entity 过滤；点击事件在中栏定位相关 target；
- **Xref**：选中事件/目标的因果链，显示“上游/下游”，点击跳转。

事件条目示例：

```text
3.10  +ghost:9000        A1/S1   sensor:RSU-01
3.10  +ghost:9001        A1/S1   sensor:RSU-01
3.15  TTC 1.481          adas    veh:eastbound.2
3.15  brake cmd #1       adas    veh:eastbound.2
3.16  speed 14.86→14.42  effect  veh:eastbound.2
3.20  ghost_object       det     rsu:RSU-01
```

底部“原始 JSON”抽屉：

- 显示当前选中事件/行的原始记录；
- 语法高亮可选，默认等宽纯文本；
- 支持复制；
- 真值数据用紫色边框并标注“演示/评估”。

### 2.5 底栏：时间轴

- 横轴：仿真时间；
- 图层：攻击区间（A1/A2…）、检查点、告警、当前 cursor；
- 拖动 cursor → 只读查看历史（live 模式下不改变仿真）；
- 点击检查点 → 跳到对应 StepFrame（如果已生成）；
- 显示“跟随最新”开关；关闭后不自动滚动。

## 3. A1 的推荐默认布局

只注册 10 个 target，不要把所有流铺开：

1. `atk:ATK001`（struct）
2. `sensor:RSU-01.objects`（table，高亮目标 RSU）
3. `sensor:RSU-02.objects`（table，对照）
4. `sensor:RSU-03.objects`（table，对照）
5. `sensor:GNB-01.objects`（table，可选折叠）
6. `veh:eastbound.2.state`（struct）
7. `veh:fleet`（table，只显示受影响）
8. `net:pc5`（struct + sparkline）
9. `det:alerts`（event）
10. `truth:...`（折叠，demo only）

中栏默认 2 列卡片；RSU 三张并排，方便一眼看出“只有一张变了”。

## 4. 交互

| 操作 | 行为 |
|---|---|
| 点击左栏 | 选中并滚动到卡片 |
| 点击卡片头 | 折叠/展开 |
| `pin` | 固定在顶部，不随过滤消失 |
| `设为基线` | 以当前帧作为 diff 基线 |
| `查看原始` | 打开右栏 JSON 抽屉 |
| `跟随最新` | 自动滚到最新事件；暂停时自动关闭 |
| `冻结` | 调用 pause；等待 ack 后 UI 显示“已停稳” |
| `下一步` | 调 step(checkpoint)，渲染返回的 StepFrame |
| `下一步 tick` | 调 step(tick)，高级选项 |
| `跳到下一次攻击` | 运行到下一个 `attack.start`/checkpoint |
| 搜索 | 按 target/field/entity 过滤 |
| 键盘 | Space 下一步、F 冻结、B 基线、Esc 取消、/ 搜索 |

原则：

- 演示时默认“冻结后阅读”，不要一边跑一边讲；
- 变化高亮必须可关闭（减少视觉噪音）；
- 所有操作有明确反馈（按钮 loading/禁用/错误 toast）；
- 不在前端做业务推断（ghost/affected/delta 都由后端给）。

## 5. 无攻击时的页面

这是必须支持的“正常态”：

- 顶部状态：`无活动攻击`；
- 左栏 Attacks 空，Truth 折叠；
- 中栏仍显示 3 RSU + gNB、fleet、PC5、DET；
- 底栏没有攻击区间，只有时间轴/告警；
- 可以“冻结/继续”，但没有 checkpoint 单步；
- 文案：“当前为正常运行；注入攻击后可在此追踪注入点与下游影响。”

## 6. 渲染与性能

### 6.1 更新策略

- SSE 到达 → 写入本地 `Map<target_id, frame>` → 标记 dirty；
- `requestAnimationFrame` 每帧最多渲染一次；
- 只重渲染 dirty 卡片；
- 表格按 key 更新行，不重建整个 `<tbody>`；
- 变化高亮用 CSS class + 定时移除，不触发全局重排；
- 事件列表用虚拟滚动/最多 500 条 DOM。

### 6.2 限流

| 场景 | 策略 |
|---|---|
| 10 Hz 正常 | 每帧合并，渲染 ≤20 fps 足够 |
| 突发 100 帧 | 合并为最新帧，事件保留 |
| 多卡片 | 只渲染可视区域；折叠卡片不更新 DOM |
| 大表 | 最多 200 行；超出虚拟滚动/截断提示 |
| 断线重连 | 先拉最新快照，再补事件；不重放全部动画 |

### 6.3 前端技术

- 原生 JS（无 React/Vue），与现有 `app.js` 风格一致；
- CSS Grid/Flex；`font-variant-numeric: tabular-nums`；
- Canvas 只用于 sparkline/时间轴；表格用 DOM；
- 不引入 CDN；离线可用；
- 复用现有 `style.css` 的色板，新增 `trace.css` 覆盖布局；
- 字体：`ui-monospace, "Cascadia Mono", "SFMono-Regular", Menlo, Consolas, "Noto Sans Mono CJK SC", monospace`；中文正文用系统 sans。

## 7. 视觉规范

| 元素 | 规则 |
|---|---|
| 背景 | `#0d1117` / 卡片 `#141b24` |
| 文本 | `#d7e0ea`；次要 `#7d8fa3` |
| 正常 | 灰蓝 |
| 变化 | 琥珀 `#f0a93b`，仅 600 ms 高亮 + 左侧色条 |
| 攻击/注入 | 红 `#e05a5a`，加 `INJECTED` 标签 |
| 告警 | 红/橙，带规则名 |
| 真值 | 紫 `#b07ae0`，默认折叠 |
| 等宽数字 | 所有 ID/坐标/指标 |
| 状态点 | running 绿、paused 琥珀、error 红 |

可访问性：

- 不只靠颜色：新增用 `NEW` 文本，变化用 `Δ`；
- 对比度 ≥ 4.5:1；
- 键盘可达；
- 动效遵循 `prefers-reduced-motion`；
- 表格有 caption/aria-label。

## 8. 空/错/慢状态

| 状态 | 展示 |
|---|---|
| 无会话 | “启动仿真后开始追踪” + 回到主控制台 |
| 无攻击 | 正常态提示，不显示空攻击卡片 |
| 断线 | 顶部黄条“连接断开，正在重连”；保留最后画面 |
| 慢客户端 | 顶部提示“已合并 N 帧 / 丢弃 M 帧” |
| trace 关闭 | “追踪未启用” + 开启方式 |
| probe 错误 | 目标卡片显示 `ERROR`，不阻塞其他卡片 |
| 回放缺数据 | 对应 target 显示“该 run 未记录”，不伪造 |

## 9. 反模式

- 把所有 18 类流都做成卡片；
- 每帧全量重绘表格；
- 用十六进制作为主视图；
- 只靠颜色表达变化；
- 前端自己解析 `sensing.objects` 猜 ghost；
- 在 live 模式下自动滚动到最新，导致演示时画面乱跳；
- 把真值和观测混在同一列表且不标注；
- 为了“像 IDA”加大量无意义的面板/闪烁。

## 10. 页面路由与文件

```text
isacsim/web/static/
├─ trace.html          # 独立页面
├─ trace.css           # 布局/组件样式
├─ trace.js            # SSE/REST/渲染
└─ style.css           # 复用色板/基础控件
```

FastAPI：

```text
GET /trace  → trace.html
GET /api/trace/* → TraceService
```

不引入构建步骤；`trace.js` 可用 ES modules 或 IIFE，建议 IIFE 与现有 `app.js` 一致。

# 快速上手与演示

## 1 安装与自检

```bash
cd ISAC_SIM
python3 -m venv .venv
.venv/bin/pip install -e ".[dev,dataset]"
./scripts/build_net.sh
.venv/bin/python -m isacsim info
.venv/bin/python -m isacsim preflight
```

`info` 会输出 CPU/内存/磁盘/SUMO 版本与默认场景的耗时、内存、磁盘估算。

## 2 三分钟演示（Web）

```bash
.venv/bin/python -m isacsim web --port 8080
```

1. 浏览器打开 `http://127.0.0.1:8080`；
2. 点"开始"，等待 1–2 s，画布出现车辆；
3. 观察"参与实体"：车辆总数、类型、位置实时变化；
4. 切到"攻击编排"，选 `A1 感知篡改 → 通信拥塞`，强度 0.7、时长 10 s，注入；
5. 回到地图：被攻击车辆出现琥珀色光环；"统计"中跨层攻击 +1、告警数上升；
6. 再注入 `A3 跨层隐蔽`，观察"雷达距离偏置"告警；
7. 体验"暂停/继续/停止/复位"；
8. "运行产物"中下载本次 zip（观测流 + 真值 + 告警）。

## 3 命令行演示

```bash
# 单剧本
.venv/bin/python -m isacsim run -a A1 --duration 20 --out out

# 四类并存
.venv/bin/python -m isacsim run -a A1,A2,A3,A4 --duration 30 --out out

# 输出示例
# { "state": "stopped", "sim_time": 30.0, "records_total": 62000, ...,
#   "attacks": {"campaigns": {"A1":1,...}, ...}, "truth_events": 4 }
```

运行目录：`out/<scene>-<seed>-<ts>/`。

## 4 批量数据集与评估

```bash
# 评估用（不落观测流，速度快）
.venv/bin/python -m isacsim batch --out out/ds --attacks 300 --normal 300 \
    --duration 15 --workers 16 --no-streams
.venv/bin/python -m isacsim eval --runs out/ds

# 带观测流（用于训练检测模型）
.venv/bin/python -m isacsim batch --out out/ds_full --attacks 50 --normal 50 \
    --duration 20 --workers 12
```

评估产物：`out/ds/report.md`、`out/ds/eval.json`。

## 5 导出到现有 5G-A-NIDD 原型

```bash
.venv/bin/python -m isacsim export nidd -i out/<run> -o out/nidd
```

产物：`d0.jsonl`、`d1.jsonl`、`d2.jsonl`、`d3a/b/c.jsonl`、`d4.jsonl`（核心网）、`d5.jsonl`（平台）、`defense.jsonl`、`chain.json`、`cam.pcapng`、`labels.json`、`ground-truth.csv`。

## 6 典型输出核对

| 核对项 | 方法 |
|---|---|
| 真值数量 | `wc -l out/<run>/truth/events.jsonl` 与页面"真值事件"一致 |
| 数据总量 | 页面记录数 ≈ 各 `*.jsonl` 行数之和 |
| 攻击计数 | `truth/events.jsonl` 中 campaign 计数与页面"跨层攻击"一致 |
| 时延 | 页面 P95 与 `out/ds/report.md` 中 `detect_latency_ms.p95` 一致 |
| 识别率/误检率 | `out/ds/report.md`，含 95% 置信区间 |

## 7 常见问题

- **启动慢 1 s**：SUMO 首次连接 TraCI 的固定开销。
- **没有车辆**：仿真开始后 1–2 s 才有车发车；确认 `assets/routes/arterial.rou.xml` 存在。
- **算力不够**：先 `preflight`；降低 `vehicles.max`、时长或关闭 `streams.graph`。
- **浏览器看不到**：用 SSH 端口转发，见 Web 文档。

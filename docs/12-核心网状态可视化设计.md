# 核心网状态可视化设计

> 目标：在左侧 Canvas 上用颜色实时展示 5G 核心网/平台节点健康状态，和车路网络共用同一视图。  
> 实现：`isacsim/layers/health.py` + `web/static/app.js` 的叠加/核心网视图。  
> 默认：叠加视图；阈值采用默认值。

---

## 1 视图结构

左侧新增三段切换：

```text
路网 | 叠加 | 核心网
```

| 模式 | 行为 |
|---|---|
| 路网 | 当前车路网络，不显示核心网 |
| **叠加（默认）** | 路网压暗，右上角浮出半透明核心网面板；gNB 保持地图真实位置，用 N2 线连到 AMF |
| 核心网 | 隐藏路网，拓扑放大居中，适合演示/汇报 |

核心网节点固定布局，不随车辆移动；gNB 是唯一地图锚点。

```text
gNB ──N2── AMF ──N11── SMF ──N4── UPF ──N6── DN ──API── V2X 平台
              │             │
             NEF          UDM / AUSF
```

## 2 节点与颜色

| 状态 | 颜色 | 视觉 |
|---|---|---|
| 健康 | 绿 `#35c48a` | 实线边框，静态 |
| 繁忙 | 橙 `#f0a93b` | 橙色边框，缓慢呼吸 |
| 拥塞/异常 | 红 `#e05a5a` | 红色边框 + 脉冲光环 |
| 未知 | 灰 `#7d8fa3` | 虚线/灰色 |
| 未启用 | 深灰 `#4b5a6a` | 半透明 |

节点右上角同时显示 `✓ / ! / × / ?`，避免只依赖颜色。  
节点下方显示 `L xx%` 或最先命中的原因（如 `queue 72%`、`route override`）。

边默认灰色；红色/橙色继承两端较严重状态；红色异常边为虚线。

## 3 健康度口径

`isacsim/layers/health.py` 统一计算：

```text
load      = max(queue_ratio, inflight_ratio, qps_ratio)
error     = 1s 滚动 reject/drop rate
latency_r = latency_ms / budget_ms

红：anomaly 或 load >= 0.85 或 error >= 5% 或 latency_r >= 1.0
橙：warning 或 load >= 0.60 或 error >= 1% 或 latency_r >= 0.70
绿：其余
```

节点特例：

| 节点 | 橙色/红色来源 |
|---|---|
| AMF | `overloaded` / queue 高 / 注册拒绝 |
| SMF | 降级 QoS 会话 / 会话失败 |
| UPF | 降级 QoS / `route_override`（红） |
| NEF | unsubscribe/revoke（红） |
| UDM/AUSF | 鉴权失败/超时 |
| DN | UPF 路由被改向（红） |
| 平台 | ingest 慢（橙）、dropped/provenance 异常/control burst/audit gap（红） |
| gNB | 附着数/负载；当前默认按附着数近似 |

每个节点 snapshot 增加：

```json
"health": {
  "status": "orange",
  "score": 0.5,
  "reasons": ["busy"],
  "metrics": {"load": 0.72, "error_rate": 0.0, "latency_ratio": 0.0}
}
```

`/api/core`、`/api/platform`、`/api/state` 均直接返回该字段，前端不重复算阈值。

## 4 交互

- 悬停节点：tooltip 显示状态、原因、负载；
- 点击节点：自动切到“网络/平台”tab；
- 图例：健康/繁忙/拥塞/未知/未启用；
- 攻击进行中：相关节点按真实 health 着色；
- 防御动作：右侧表展示 `defense.action`，后续可在节点上加盾牌图标；
- 无 core 数据/旧后端：显示“核心网未启用或后端版本过旧”。

测试钩子：

- `canvas.dataset.viewMode`：`road/overlay/core`
- `canvas.dataset.coreNodes`：绘制节点数
- `canvas.dataset.coreStatuses`：`gnb:green,amf:red,...`

UI 冒烟已验证：默认叠加视图、9 个节点绘制、核心网视图切换、A1 注入、网络/平台视图、暂停/停止。

---

## 6 边界

- `queue_depth` 目前是语义近似（A5/A10 由攻击设置，正常为 0），不是真实 5GC 队列；
- 边健康由两端节点状态继承，尚未按接口单独统计时延/丢包；
- 没有历史曲线；后续可加 sparkline；
- 颜色阈值集中在 `health.py`，但尚未暴露到 YAML；
- 该视图是运维/研究可视化，不是 5GC 网管。

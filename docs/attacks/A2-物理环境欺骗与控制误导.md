# A2 物理环境欺骗 + 控制指令误导：代码走读与实现解析

> 代码基线：`feature/trace-watch`（v0.3.0 + A1–A10 TraceProfile），2026-11-03。
> 共享机制见 [A1 §2–§4](A1-感知篡改诱导通信拥塞.md)；本文只写 A2 的差异。
> 目标：从 A2 启动开始，走完“伪造停止牌 → 注入制动 → 链路干扰 → 真值 → 检测”，并说明哪些是代码保证、哪些是声明。

## 1. 一句话概括

A2 做三件事，而且**不依赖 ADAS**：

1. 在目标 RSU 的 `sensing.objects` 里追加一个静止的 `stop_sign`；
2. 从 `t0+1.0 s` 起直接调用 `ControlLayer.inject_brake()`，向受害车发一条 `reason=injected` 的制动指令；
3. 每个 tick 给 `ctx.extras["link_jam"]` 加一个标量，让 V2X 信道模型的 CBR/PER/时延变差。

A1 的制动是“ADAS 看到幽灵后自己产生的”；A2 的制动是攻击者直接写进控制面的。两条链在 `control.command` 上看起来都像合法制动，但 `src/reason/ttc` 不同。

## 2. 端到端调用链

```text
POST /api/attacks {type:"A2", amplitude, duration, start}
  → AttackScheduler.submit()
  → CampaignA2.start(ctx)                 campaigns.py:142
      ├─ pick_rsu(seed+1)
      ├─ pick_vehicle(seed,"a2") 或 seed+1
      ├─ ghost_object(veh, 9100, 28m, cls="stop_sign")
      ├─ hook("sensing.objects")           只改目标 RSU
      └─ truth.add()                       scheduler.py:48
  → 每个 tick CampaignA2.tick(ctx)        campaigns.py:162
      ├─ extras["link_jam"] += jam
      └─ t >= t0+1.0 且未注入过：
          control.inject_brake(decel=3.0..5.5, duration=1.8)
```

层序（[engine.py](../../isacsim/core/engine.py:123)）：

```text
scheduler → sensing → v2x → uu → core → auth → platform → control → task
```

- `link_jam` 在 scheduler 写入，同一 tick 的 `v2x.tick()` 立刻消费；
- `inject_brake()` 在 scheduler 调用，同一 tick 就能发出 `control.command`；
- 目标 RSU 的 `sensing.objects` 在 sensing 阶段被 hook 改写。

## 3. 选目标与参数

### 3.1 选目标

```python
rsu = pick_rsu(self.scene, ctx, self.seed + 1)
veh = pick_vehicle(ctx, self.seed, "a2") or pick_vehicle(ctx, self.seed + 1, "a2")
if veh is None or rsu is None:
    self.finished = True
    return
```

- RSU 和车辆是**独立选择**的；
- 没有检查受害车是否被该 RSU 覆盖、是否装备、是否有 ADAS；
- 但 A2 的制动是直接注入的，所以即使 ADAS 不看目标列表，控制指令仍然会到车。

### 3.2 强度映射

`_level()`（[campaigns.py](../../isacsim/attacks/campaigns.py:21)）：

| 量 | 公式 | `a=0.8` 实测 |
|---|---|---:|
| 停止牌位置 | 车前 28 m | x=195.2 |
| `jam` | `0.05 + 0.35a` | 0.33 |
| 制动减速度 | `3.0 + 2.5a` m/s² | 5.0 |
| 制动持续时间 | 固定 1.8 s | 1.8 s |
| 注入时刻 | `t0 + 1.0 s` | 3.0 s（t0=2.0） |

A2 的 `sign_at` 在真值里是**停止牌的 x 坐标**，不是时间；容易误读。

## 4. 注入点

### 4.1 目标列表：停止牌

```python
self.sign = ghost_object(veh, 9100, dist=28.0, cls="stop_sign")

def hook(payload, _ctx):
    if payload.get("sensor_id") != self.rsu_id:
        return payload
    payload["objects"] = list(payload.get("objects", [])) + [dict(self.sign)]
    return payload

self.hook(ctx, "sensing.objects", hook)
```

`ghost_object()` 生成的是静止世界坐标（[base.py](../../isacsim/attacks/base.py:62)）：

- `entity=ghost:9100`，`vx=vy=0`；
- `cls=stop_sign`，`confidence=0.92`，`tracked_age=50`；
- 只进入目标 RSU 的 `sensing.objects`，不进入雷达回波/点迹。

### 4.2 控制面：直接制动

`ControlLayer.inject_brake()`（[control.py](../../isacsim/layers/control.py:144)）最终调用 `_command()`（[control.py](../../isacsim/layers/control.py:105)）：

```python
self._command(ctx, veh, ttc=99.0, reason="injected",
              source=f"attacker:ctl-{vid}", decel=decel, duration=duration)
```

实测 seed=14、a=0.8：

```json
{
  "stream": "control.command",
  "source": "attacker:ctl-southbound.0",
  "entity": "veh:southbound.0",
  "payload": {
    "src": "attacker:ctl-southbound.0",
    "dst": "southbound.0",
    "cmd_type": "brake",
    "params": {"decel_mps2": 5.0, "ttc_s": 99.0},
    "reason": "injected"
  }
}
```

这条指令和 A1 的 `reason=ttc, src=adas:*` 明显不同；检测侧可以用 `ttc_s >= 10` 抓到它。

### 4.3 链路：`link_jam`

`CampaignA2.tick()` 每个 tick 累加：

```python
ctx.extras["link_jam"] = ctx.extras.get("link_jam", 0.0) + self.jam
```

`ctx.extras` 每 tick 重建，所以必须每个 tick 重加。V2X 的 `_channel()`（[v2x.py](../../isacsim/layers/v2x.py:36)）把它直接加到 CBR，并提高 PER：

```text
cbr = min(0.98, 0.92 × offered / 1200 + jam)
per = min(0.95, base_per + jam × 0.6)
```

注意：`jam` 不是“发了多少包”，而是信道模型里的等效干扰量。

## 5. 下游消费

| 消费者 | 看到什么 | 结果 |
|---|---|---|
| ADAS | 目标 RSU 的目标列表多了 stop_sign | 可能额外触发一次 TTC 制动；不是 A2 的必要条件 |
| ControlLayer | 攻击者直接 `inject_brake` | 必然产生 `control.command`（只要车还在） |
| V2X | `link_jam` | CBR/PER/时延变差；可能触发 `pc5.rise` |
| Trace | `ghost.added`、`control.command`、`pc5.rise`、`vehicle.speed_drop` | A2 profile S1–S5 |
| Truth | `nodes=[rsu, victim, attacker]` | `domains=[perception, control, link]` |

## 6. 真值

`CampaignA2.truth()`（[campaigns.py](../../isacsim/attacks/campaigns.py:174)）实测：

```json
{
  "nodes": ["rsu:RSU-01", "veh:southbound.0", "attacker:A2"],
  "domains": ["perception", "control", "link"],
  "params": {"sign_at": 195.2, "jam": 0.33, "victim": "southbound.0"},
  "envelope": {"in_envelope": true, "criterion": "jam >= 0.05"},
  "stages": [
    {"name": "伪造停止牌", "t0": 2.0, "t1": 3.0},
    {"name": "注入制动指令", "t0": 3.0, "t1": 5.0},
    {"name": "链路干扰", "t0": 3.0, "t1": 5.0}
  ],
  "causal_chain": [
    "sensing.objects:spoof_sign",
    "control.command:inject",
    "link:jam",
    "veh:hard_brake"
  ]
}
```

`stages` 的“注入制动/链路干扰”从 `t0+1` 开始，而 `link_jam` 实际从 `t0` 就开始加；这是叙述分界，不是代码开关。

## 7. 检测侧看到了什么

A2 的相关规则：

| 规则 | 触发 | 实测 |
|---|---|---|
| `ghost_object` | `stop_sign` 连续 2 帧、无多 RSU 互证、不靠近地图静态物 | 2 条 |
| `brake_without_hazard` | `control.command.params.ttc_s >= 10` | 1 条 |
| `cbr_spike` | CBR>0.7 且 3 s 内上升>0.2 | 短场景通常不触发 |
| `link_degraded` | PER>0.5 | 短场景通常不触发 |

seed=14、a=0.8、3 s 攻击的实测告警：

```text
ghost_object ×2, brake_without_hazard ×1
```

`brake_without_hazard` 是最稳定的 A2 证据；`ghost_object` 依赖停止牌所在位置与地图先验。

## 8. 时序（seed=14，a=0.8，t0=2.0）

| 相对 `t0` | 事件 |
|---:|---|
| 0 | 生成停止牌；注册 `sensing.objects` hook；写 `link_jam` |
| 0 | 目标 RSU 目标列表出现 `ghost:9100` |
| +0.05 | 第一条带新 CBR 的 `link.metrics` |
| +1.0 | `inject_brake()` 发出 `control.command` |
| +1.12 | `pending` 落地，SUMO `slowDown` |
| +1.0～ | 车辆减速，Trace 产生 `vehicle.speed_drop` |
| `t1` | 摘 hook；`link_jam` 不再加 |

## 9. 边界与差异

1. **停止牌不一定被 ADAS 消费**：目标 RSU 可能不是受害车的服务传感器；但 A2 的制动是直接注入的，所以不影响“有制动”这件事。
2. **停止牌不是 A2 的制动原因**：A2 不依赖 ADAS；即使 ADAS 没看到停止牌，`inject_brake` 仍会执行。
3. **`link_jam` 是全局标量**：所有 V2X 流量都受影响，不是只影响受害车。
4. **`sign_at` 是坐标**：不是“第几秒注入”。
5. **`stop()` 只摘 hook**：`ctx.extras` 本身每 tick 重建，所以下一 tick 不会继续加 `link_jam`；但已经落地的 `pending` 制动仍会执行到结束。
6. **真值 `stages` 是计划**：没有代码分支保证“t0+1 才进入 S2”。

## 12. 小结

```text
目标 RSU 目标列表 + stop_sign
        │
        ├─ ADAS 可能额外制动（非必要）
        │
control.inject_brake(ttc=99, reason=injected)
        │
        └─ control.command → SUMO slowDown

每 tick link_jam → CBR/PER/时延上升
```

A2 的关键不是“假停止牌让 ADAS 刹车”，而是**攻击者绕过 ADAS，直接向控制面写了一条制动指令**；假停止牌和链路干扰是并行的跨层伪装。

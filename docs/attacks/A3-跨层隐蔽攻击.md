# A3 跨层隐蔽攻击（雷达回波渐偏）：代码走读与实现解析

> 代码基线：`feature/trace-watch`（v0.3.0 + A1–A10 TraceProfile），2026-11-03。
> 共享机制见 [A1 §2–§4](A1-感知篡改诱导通信拥塞.md)；本文只写 A3 的差异。
> 目标：解释“雷达回波距离随时间线性偏移 → 点迹随之偏移 → 60% 处小制动”的真实代码路径，以及“隐蔽”在哪些地方成立、哪些地方不成立。

## 1. 一句话概括

A3 做两件事：

1. 在 `sensing.radar.echo` 上，对受害车的 `range_m` 按攻击进程加一个线性增长的偏置；
2. 在攻击时长的 60% 处，直接调用 `ControlLayer.inject_brake(decel=1.2, duration=0.8)`。

它**不改** `sensing.objects`，也**不改** `sensing.radar.track` 的原始记录；点迹偏移是 sensing 层从被改过的回波重新计算出来的。所谓“telemetry mask”只在真值 `causal_chain` 里声明，当前没有实现。

## 2. 端到端调用链

```text
POST /api/attacks {type:"A3", amplitude, duration, start}
  → CampaignA3.start(ctx)                 campaigns.py:204
      ├─ pick_vehicle(seed,"a3")
      ├─ bias_max = _level(a, 0.8, 3.0)
      └─ hook("sensing.radar.echo")       只改 entity=veh:<victim>
  → 每个 tick CampaignA3.tick(ctx)        campaigns.py:225
      └─ t >= t0 + duration×0.6：
          control.inject_brake(decel=1.2, duration=0.8)
```

层序：

```text
scheduler → sensing → v2x → uu → core → auth → platform → control
```

- `sensing._emit_frame()` 先 emit `sensing.radar.echo`，hook 改完后返回 `final_echo`；
- 同一函数用 `final_echo` 计算 `sensing.radar.track`（[sensing.py](../../isacsim/layers/sensing.py:146)）；
- `control.tick()` 在 sensing 之后，60% 的制动会直接发 `control.command`。

## 3. 选目标与强度

```python
veh = pick_vehicle(ctx, self.seed, "a3")
self.bias_max = _level(self.spec.amplitude, 0.8, 3.0)
entity = f"veh:{self.veh_id}"
```

| 量 | 公式 | `a=0.8` 实测 |
|---|---|---:|
| 最大偏置 | `0.8 + 2.2a` m | 2.56 m |
| 制动时刻 | `t0 + duration×0.6` | 3.8 s（t0=2，duration=3） |
| 制动减速度 | 固定 1.2 m/s² | 1.2 |
| 制动时长 | 固定 0.8 s | 0.8 |
| 包络 | `bias >= 1.0 m` | true |

`spec.target` 不生效；受害车由 `pick_vehicle()` 选。A3 只选一辆车，所有能看到它的传感器都会收到同一个偏置。

## 4. 注入点：只改回波

```python
def hook(payload, _ctx):
    if payload.get("entity") != entity:
        return payload
    frac = max(0.0, min(1.0, (_ctx.t - self.t0) / max(self.spec.duration, 1e-6)))
    payload["range_m"] = round(float(payload["range_m"]) + self.bias_max * frac, 3)
    self._modified += 1
    return payload

self.hook(ctx, "sensing.radar.echo", hook)
```

关键点：

- 只匹配 `entity=veh:<victim>`，因此 4 个传感器的同一辆车都被改；
- `frac` 从 0 线性到 1，`t0` 时偏置为 0，`t0+duration` 时达到 `bias_max`；
- 改的是 `range_m`，不是 `x/y`；点迹的 `pos_x/pos_y` 仍是车辆真实位置；
- `radial_vel_mps`、`azimuth_deg`、`snr_db` 等没有改，所以“回波距离与点迹几何”会出现矛盾；
- `_modified` 只计数，没有落盘，也没有在 `truth()` 中使用。

### 4.1 点迹为什么会跟着偏

`sensing._emit_frame()`（[sensing.py](../../isacsim/layers/sensing.py:146)）：

```python
final_echo = ctx.emit("sensing.radar.echo", ...)
if final_echo is not None:
    base = final_echo
    track = {
        ...
        "range_m": round(base["range_m"] + rng.normal(0.0, 0.05), 3),
        ...
        "pos_x": round(veh.x + rng.normal(0.0, 0.15), 3),
        "pos_y": round(veh.y + rng.normal(0.0, 0.15), 3),
    }
    ctx.emit("sensing.radar.track", ...)
```

- `range_m` 直接继承被改过的回波；
- `pos_x/pos_y` 用真实车辆位置；
- 所以检测器可以用 `range_m - hypot(pos_x/pos_y - sensor)` 得到残差。

### 4.2 60% 处的小制动

```python
if not self._cmd_done and ctx.t >= self.t0 + self.spec.duration * 0.6:
    self._cmd_done = True
    control.inject_brake(ctx, self.veh_id, decel=1.2, duration=0.8)
```

它直接进控制面，不依赖 ADAS；`ttc=99`、`src=attacker:ctl-*`、`reason=injected`。减速度刻意很小，和 A2 的 3–5.5 m/s² 区分。

## 5. 下游消费与跨层证据

| 证据 | A3 下的表现 |
|---|---|
| `sensing.radar.echo` | 同一 victim 的 `range_m` 随时间增长 |
| `sensing.radar.track` | `range_m` 跟着增长，但 `pos_x/pos_y` 仍是真实位置 |
| `sensing.objects` | 不变；目标列表仍正常 |
| `control.command` | 60% 处一条 `reason=injected, decel=1.2` |
| `vehicle.speed_drop` | 若 0.8 s 制动使速度下降 ≥0.5 m/s，则出现 |
| `link.metrics` | 不直接受影响 |

“隐蔽”来自两点：单帧偏置低于常规检测门限；目标列表/物理位置没有明显异常。但**多帧累积残差**可以抓到它。

## 7. 检测侧看到了什么

### 7.1 `radar_range_bias`

`_on_track()`（[reference.py](../../isacsim/detect/reference.py:130)）对每个 `(sensor, target_id)` 保存最近 6 个残差：

```python
resid = range_m - true_range
hist.append(resid)
if len(hist) >= 5:
    vals = sorted(hist)[1:-1]
    mean = sum(vals) / len(vals)
    if mean > 1.5:
        streak += 1
        if streak >= 3:
            alert("radar_range_bias")
```

- 需要至少 5 帧、连续 3 次均值 >1.5 m；
- A3 的偏置是渐进的，短场景（3 s）里可能还没满足条件；
- seed=14、a=0.8、3 s 攻击的实测只出现 `brake_without_hazard`，没有 `radar_range_bias`；把攻击拉长到 8–10 s 更容易看到。

### 7.2 `brake_without_hazard`

`ttc_s=99`，必然命中（只要控制指令发出）。它抓到的是 A3 的第二阶段，不是雷达偏置本身。

### 7.3 实测告警

```text
brake_without_hazard ×1
```

`radar_range_bias` 在当前短场景没有出现，说明“隐蔽”确实有效；不能把“有偏置”写成“必然告警”。

## 8. 外部检测视角：数据支撑、`/trace` 位置与 `out/` 落点

> 本节假设判定在仿真之外完成：只看导出的观测流与日志，不读 `truth/`、不读 `ctx.extras`。可观测面清单与路径/落盘规则见 [A1 §9.1、§9.4](A1-感知篡改诱导通信拥塞.md)。

### 8.1 判定 A3 需要的数据支撑

A3 只改 `sensing.radar.echo` 的 `range_m`，点迹由被改回波派生，目标列表/CAM/GNSS 全部正常。外部系统要抓的是**距离残差的时间序列**，而不是单帧阈值。

| 观测面 | 需要捕获的字段 | 在判定中的作用 | 可依赖度 |
|---|---|---|---|
| `sensing.radar.echo` | `entity`、`frame_seq`、`range_m`、`azimuth_deg`、`radial_vel_mps`、`snr_db` | 同一 victim 的 `range_m` 随时间增大，方位角/径向速度基本不变 | 物理证据 |
| `sensing.radar.track` | `sensor_id`、`target_id`、`range_m`、`pos_x/pos_y` | 残差 `range_m - ‖pos - sensor‖` 单调增大 | 物理证据（关键） |
| 传感器位姿 | `scenario.json.sensors[].{id,x,y,yaw_deg,fov_deg}` | 计算真实距离，残差才可复核 | 先验 |
| `sensing.objects` / `v2x.cam` / `sensing.gnss` | 位置、速度 | 全部正常 → 排除 A1/A2/A4 | 反证 |
| `control.command` | `reason`、`params.ttc_s`、`params.decel_mps2` | 60% 处一条 `ttc=99`、`decel=1.2` 的小指令 | 物理/协议证据 |
| `link.metrics` | `cbr`、`jam` | 不变 → 排除 A1/A2 的拥塞路径 | 反证 |

关键点：`sensing.radar.track.pos_x/pos_y` 是**独立的位置测量**（世界坐标加噪），不是由 `range_m/azimuth_deg` 反演出来的；两者的差就是可复核的残差，不需要读真值。

判定口径：

```text
K1 对每个 (sensor,target_id) 计算 resid=range_m-‖pos-sensor‖；
   6 帧滑窗去极值后均值 >1.5 m、连续 3 次 → 报“距离偏置”。
K2 回波 range 相对首帧的增量近似线性，斜率≈bias_max/duration（0.8–3 m 渐偏）。
K3 objects/cam/gnss 正常 → 不是 A1/A2/A4。
K4 control.command 的 ttc_s=99、decel<=1.5，且没有对应的危险目标。
=> K1∧K4（±1 s）判 A3；只有 K1 判“雷达数据质量异常”，只有 K4 判“异常制动”。
```

边界：

- 短场景（3 s）常常凑不满“5 帧 + 连续 3 次”，`radar_range_bias` 不出现——不能据此判“无偏置”；
- 点迹不是独立测量：回波被删，点迹也不会产生；
- 静态物没有回波，A3 也不涉及静态物，所以“某目标无回波”在本类里没有判别力；
- 真值里的 `telemetry:mask` 当前没有实现，不存在“遥测被掩盖”的专门证据。

### 8.2 对应前端 `/trace` 的位置

| 数据 | `/trace` 位置 | 看什么 |
|---|---|---|
| 回波偏移 | 右栏 **TRACE** 的 `radar.echo` 事件 → **DETAIL** | 每个 tick 每车最多 1 条采样：`range_m` 逐 tick 变大、`frame_seq` 递增 |
| 点迹随动 | 右栏 `radar.track` 事件 | 派生 `range_m` 同样变大，附 `sensor_id` |
| 目标列表 | **感知** → `感知 · 目标列表` 卡 | 正常（这正是 A3 的隐蔽性） |
| 制动 | **车辆** → `<victim> · state` 卡；右栏 `control.command` | `last_command.decel=1.2`、`ttc=99`、`speed_drop` |
| 告警 | **总览** → `Detector · alerts`；**底栏时间轴**红点 | `brake_without_hazard`；`radar_range_bias` 取决于窗口长度 |
| 阶段 | 顶栏 **下一步** 后的检查点横幅 | S1 回波偏移 → S2 点迹随动 → S3 小制动 → S4 轻微减速 → S5 告警 |

不在 `/trace` 上的：雷达卡片与残差曲线（页面没有）、回波/点迹全量序列（事件只是每 tick 的采样）、`sensing.gnss`。仅靠 `/trace` 能看出“range 在涨”，但要下“偏置”的结论必须回 `out/` 算残差。

### 8.3 对应后端 `out/` 的位置

| 数据 | 文件 | 过滤键 / 字段 | 备注 |
|---|---|---|---|
| 回波 | `sensing.radar.echo.jsonl` | `.payload.entity=="veh:<victim>"` | 按 `frame_seq` 排序 |
| 点迹 | `sensing.radar.track.jsonl` | 同上；带 `pos_x/pos_y` | 残差来源 |
| 传感器位姿 | `scenario.json` | `.sensors[]` | 计算真实距离 |
| 制动 | `control.command.jsonl` | `params.decel_mps2==1.2`、`params.ttc_s==99` | 60% 处一条 |
| 告警 | `alerts.jsonl` | `radar_range_bias` / `brake_without_hazard` | 仅 CLI/batch |
| 真值（评估侧） | `truth/events.jsonl` | `.campaign=="A3"` | `params.bias_max_m/ramp_s` |

```bash
cd out/doc_a3/arterial-14-*
python3 - <<'PY'
import json, math
sensors = {s["id"]: (s["x"], s["y"]) for s in json.load(open("scenario.json"))["sensors"]}
for line in open("sensing.radar.track.jsonl"):
    p = json.loads(line)["payload"]
    sx, sy = sensors[p["sensor_id"]]
    true_range = math.hypot(p["pos_x"] - sx, p["pos_y"] - sy)
    print(p["sensor_id"], p["target_id"], p["frame_seq"], round(p["range_m"] - true_range, 2))
PY
```

> 判 A3 的关键不是“range 大”，而是“range 与位置测量不一致，且不一致在单调增长”。

## 9. 时序

| 相对 `t0` | 事件 |
|---:|---|
| 0 | 注册回波 hook；写 `sensing.radar.echo` 时开始加偏置 |
| +0.05 | 第一帧带偏置的回波/点迹 |
| +1.8 | 偏置达到 `bias_max×0.6` |
| +1.8 | `inject_brake(1.2, 0.8)` |
| +1.92 | SUMO `slowDown` 落地 |
| +2.4 | 偏置达到 `bias_max×0.8` |
| `t1` | 摘 hook，回波恢复正常 |

## 10. 边界与差异

1. **`telemetry:mask` 未实现**：没有专门的遥测掩盖事件。
2. **只改 `range_m`**：`pos_x/pos_y`、`velocity`、`objects` 不变；这既是隐蔽性来源，也是检测入口。
3. **点迹不是独立测量**：它由被改回波派生；如果 hook 删除回波，点迹也不会产生。
4. **短场景不一定触发 `radar_range_bias`**：需要 5 帧 + 3 次确认。
5. **真值 `nodes` 的 gNB 不是动态选择**：不要把它当作“服务传感器”。
6. **`spec.target` 不生效**：victim 由 `pick_vehicle()` 选。

## 13. 小结

```text
sensing.radar.echo.range_m += bias_max × frac
        │
        └─ sensing.radar.track.range_m 继承偏置
              │
              └─ 多帧残差 → radar_range_bias（需要时间）

t0 + 60% → control.inject_brake(1.2, 0.8) → brake_without_hazard
```

A3 的核心是“单帧看起来正常、多帧才显形”的慢漂移；目标列表不变、物理位置不变，所以它不能靠 `ghost_object` 抓到。

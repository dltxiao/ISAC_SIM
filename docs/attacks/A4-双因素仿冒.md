# A4 双因素仿冒：代码走读与实现解析

> 代码基线：`feature/trace-watch`（v0.3.0 + A1–A10 TraceProfile），2026-11-03。
> 共享机制见 [A1 §2–§4](A1-感知篡改诱导通信拥塞.md)；本文只写 A4 的差异。
> 目标：解释“克隆通信标识 + 复制信道指纹 + 伪标识 CAM”在代码里到底做了什么，以及为什么它不是完整的 Uu 仿冒。

## 1. 一句话概括

A4 做三件事：

1. 在 `start()` 里发一条 `auth.cert` 克隆事件（`cloned=true`）；
2. 每个伪造周期发一条 `auth.fingerprint`（复制受害车的 CFO/IQ/RSSI）；
3. 用受害车的伪标识发一条位置偏移 45 m 的 `v2x.cam`（`cloned=true`）。

当前实现**没有** `uu.attach`、没有真正复制证书链、也没有让攻击者接入核心网；`auth.cert` 是语义事件，不是密码学验证结果。

## 2. 端到端调用链

```text
POST /api/attacks {type:"A4", amplitude, duration, start}
  → CampaignA4.start(ctx)                 campaigns.py:266
      ├─ 选已装备车辆 victim
      ├─ baseline_fingerprint(victim)
      ├─ emit auth.cert(cloned=true)
      └─ spoof_rate = _level(a, 2, 20)
  → 每个 tick CampaignA4.tick(ctx)        campaigns.py:290
      └─ 到达伪造周期：
          emit v2x.cam(cloned=true, x=+45, y=+8)
          emit auth.fingerprint(cloned=true)
```

A4 不经过 HookBus；两条伪造记录都是 `ctx.emit()` 直接产生。A4 也没有控制面动作，所以不会产生 `control.command`。

## 3. 选目标与参数

```python
equipped = [v for v in sorted(ctx.vehicles)
            if is_equipped(v, self.scene.vehicles.equipped_ratio)]
self.victim = stable_pick(equipped, self.seed, "a4")
self.spoof_rate = _level(self.spec.amplitude, 2.0, 20.0)
```

- 只从已装备车辆里选 victim；
- `spoof_rate` 是**每秒伪造次数**，不是 msg/s 的物理发送速率；
- `period = 1 / max(0.5, spoof_rate)`；
- `spec.target` 不生效。

| `a` | `spoof_rate` | 周期 |
|---:|---:|---:|
| 0.0 | 2 Hz | 0.5 s |
| 0.5 | 11 Hz | 0.091 s |
| 0.8 | 16.4 Hz | 0.061 s |
| 1.0 | 20 Hz | 0.05 s |

## 4. 注入点

### 4.1 `auth.cert` 克隆

```python
ctx.emit("auth.cert", "ATK-A4", f"attacker:{self.victim}", {
    "node_id": self.victim,
    "event": "clone",
    "cert_id": f"CERT-{self.victim}-clone",
    "pseudonym": f"PN-{self.victim}",
    "status": "valid",
    "cloned": True,
})
```

只在 `start()` 发一次；`cert_id` 是拼接出来的，没有做证书签名/链验证。

### 4.2 `auth.fingerprint` 复制

```python
ctx.emit("auth.fingerprint", f"ATK-{self.victim}", f"veh:{self.victim}", {
    "node_id": self.victim,
    "cfo_ppm": self._fp["cfo_ppm"],
    "iq_gain_db": self._fp["iq_gain_db"],
    "iq_phase_deg": self._fp["iq_phase_deg"],
    "rssi_dbm": round(self._fp["rssi_base_dbm"] + 4.0, 1),
    "auth_result": "pass",
    "cloned": True,
})
```

指纹来自 `baseline_fingerprint(victim)`（[auth.py](../../isacsim/layers/auth.py:16)），是稳定哈希生成的设备偏差；A4 把同一组值复制到攻击者记录里，并给 RSSI 加 4 dB，制造“位置不符但指纹一致”的矛盾。

### 4.3 伪标识 CAM

```python
x = victim.x + 45.0
y = victim.y + 8.0
ctx.emit("v2x.cam", f"ATK-{self.victim}", f"veh:{self.victim}", {
    "sender_pseudo": self.victim,
    "pseudonym": f"PN-{self.victim}",
    "posx": round(x, 3), "posy": round(y, 3),
    "rate_hz": 10.0,
    "cert_status": "valid",
    "cloned": True,
})
```

- 伪 CAM 使用 victim 的 `sender_pseudo`，但位置偏移 45 m / 8 m；
- `cert_status=valid`，所以单看认证字段是合法的；
- `rate_hz=10.0` 是攻击者填的值，不代表实际伪造周期（周期由 `spoof_rate` 决定）；
- 真实受害车自己的 `v2x.cam` 仍在发，检测器会看到同一标识在短时间内出现在两个相距很远的位置。

## 5. 下游消费

| 消费者 | 看到什么 |
|---|---|
| ReferenceDetector | 同一 `sender_pseudo` 的位置跳变；CAM 与 GNSS 不一致 |
| Trace | `record.clone`（auth.cert/fingerprint）、`v2x.cam.clone` |
| Platform | 伪 CAM 不在 `v2x_outbox` 里，不会自动进入平台 ingest；它是直接 emit 的记录 |
| Truth | `domains=[auth,v2x]`，没有 `uu`/`control` |

A4 当前没有让平台或核心网“接受攻击者接入”，所以不能把它描述成“攻击者成功附着”。

`causal_chain` 只有 auth/v2x；`uu:ghost_attach` 已从真值移除，因为当前没有实现。

## 7. 检测侧看到了什么

| 规则 | 触发 |
|---|---|
| `cam_position_jump` | 同一 `sender_pseudo` 1 s 内位置跳变 >25 m |
| `cam_gnss_mismatch` | CAM 位置与 GNSS 位置差 >12 m 且时间差 <0.5 s |
| `ghost_object` | A4 不产生 |
| `brake_without_hazard` | A4 不产生（没有控制指令） |

seed=14、a=0.8、3 s 攻击的实测：

```text
cam_position_jump ×3, cam_gnss_mismatch ×3
```

注意：检测器**没有**“证书克隆”或“指纹复制”的专用规则；`auth.cert`/`auth.fingerprint` 主要作为后续溯源证据。

## 8. 时序

| 相对 `t0` | 事件 |
|---:|---|
| 0 | 选 victim；发 `auth.cert(clone)` |
| +0.061 | 第一条伪 CAM + `auth.fingerprint`（a=0.8） |
| +0.1 | 检测器可能出现 `cam_position_jump` |
| 每个周期 | 重复伪 CAM + 指纹 |
| `t1` | 停止；没有 `stop()` 覆写，base 只摘 hook（A4 没有 hook） |

## 9. 边界与差异

1. **不是完整双因素仿冒**：没有证书链验证、没有 Uu 附着、没有真实射频指纹。
2. **`auth.cert` 只发一次**：后续重复的是 `auth.fingerprint` 和 `v2x.cam`。
3. **伪 CAM 不进平台 outbox**：平台 ingest 不会自动消费它；它是给记录/检测器看的直接事件。
4. **`rate_hz=10.0` 是伪造值**：实际周期由 `spoof_rate` 决定。
5. **A4 没有控制面后果**：不会产生 `control.command`，truth 也不声明 control。
6. **Trace 归因**：A4 用 `victim` 字段而非 `veh_id`；当前 `TraceService` 已把 `victim` 纳入归因，事件可以带 `attack_id`。

## 12. 小结

```text
克隆 auth.cert（一次）
        │
每个伪造周期：
  v2x.cam(sender=victim, pos=+45/+8, cloned=true)
  auth.fingerprint(复制 CFO/IQ/RSSI, cloned=true)
        │
        └─ 同一标识位置跳变 / CAM-GNSS 不一致
```

A4 的“双因素”是**标识 + 信道指纹**两个语义层同时伪造；它不是密码学攻击，也不是 Uu 接入攻击。检测靠的是位置与指纹/几何的矛盾，而不是证书校验。

## 3 指标验收

### 3.1 事件级：500 攻击 + 500 正常

命令：

```bash
.venv/bin/python -m isacsim batch --out out/m6_500_500 \
  --attacks 500 --normal 500 \
  --types A1,A2,A3,A4,A5,A6,A7,A8,A9,A10 \
  --duration 15 --workers 18 --no-streams
.venv/bin/python -m isacsim eval --runs out/m6_500_500
```

结果（`out/m6_500_500/eval.json`）：

| 指标 | 结果 |
|---|---|
| 运行数 | 1000（攻击 500，正常 500） |
| 识别率 | **100.00%**（500/500，95% CI 99.24%–100%） |
| 误检率 | **0.20%**（1/500，95% CI 0.04%–1.12%） |
| 检测时延 | P50 0.044 ms / P95 0.133 ms / P99 0.214 ms（n=6044） |
| 分类型 | A1–A10 各 50，全部 100% |

**误报样本**：`train-100419-normal`，seed 100419，`radar_range_bias`，t=10.25 s，去极值均值残差 1.71 m（门限 1.5 m）。这是正常噪声触发的已知边界，不是攻击注入。

### 3.2 链级

| 指标 | 结果 | 说明 |
|---|---|---|
| 链数 | 500 | 每个攻击 run 1 条 |
| 节点召回 | **55.28%** | 预测节点 ∩ truth 节点 / truth 节点 |
| 节点精确率 | **100%** | 预测节点均为 truth 节点 |
| 根因 top-1 | **70%** | 预测 root 与 truth 首节点/chain.root 一致 |
| 阶段覆盖 | **100%** | 预测阶段数 / truth 阶段数（上限 1） |

**边界**：参考链构建器只从告警实体提取节点，不推断未直接告警的 `attacker:`/`tenant:` 节点；55.28% 是参考实现指标，不是最终链模型指标。

### 3.3 性能与数据量

| 场景 | 结果 |
|---|---|
| 60 s / 60 车，含 core/platform，无落流 | **16.79 s**，215,472 条 / 104.8 MB，RSS 55.7 MB |
| 对照 v0.2.0 60 s | 212,464 条；**+1.4%** |
| 1000×15 s，18 进程，不落流 | **198.4 s**；产物 41 MB |

## 5 已知边界与风险

1. **参考检测器同源开发**：100% 只对本环境、本包络、本参数成立；正式模型需独立复测。
2. **误检率区间**：500 正常样本、1 次误报，Wilson 上界 1.12%。若验收要求“区间也 ≤1%”，需扩到 ≥1000 正常样本且 ≤2 次误报（最好 0 次）。
3. **链级节点召回 55.28%**：参考链构建器只从告警实体取节点；正式链模型应补充未直接告警的 attacker/tenant 节点。
4. **语义级而非协议级**：核心网/平台是状态机事件，不是 NAS/NGAP/PFCE/GTP-U 编码；不承诺 pcap/DPI。
5. **PC5 仍是语义模型**：没有 5G-A PC5 协议级；UERANSIM/Open5GS 点验属于方案2，未纳入本期。
6. **A5/A7/A9 等为受控注入**：攻击效果通过事件注入和状态机方法实现，未接真实 5GC/真实平台。
7. **Web 控制台无鉴权**：新增防御按钮后风险更高；建议加 token 或限制来源网段。

## 8 建议

1. **合并前**：补 1000+1000 正常集，或至少 1000 正常样本，把误检率 CI 上界压到 ≤1%。
2. **正式模型**：用外部检测模型替换 `ReferenceDetector`，保持同一数据契约与评估口径。
3. **链模型**：用正式图/序列模型替换告警级链构建器，重点提升节点召回。
4. **可选点验**：用 Open5GS + UERANSIM 做小规模协议级点验，但不要替换语义主循环。

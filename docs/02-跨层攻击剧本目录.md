# 跨层攻击剧本目录

> 逐攻击的代码走读、注入点、真值与检测见 [docs/attacks](attacks/README.md)；其中“外部检测视角”一节给出判定所需数据、`/trace` 位置与 `out/` 落点。本文件保留剧本目录与参数定义。

## 1 设计原则

1. **跨层**：每个剧本至少覆盖两个域（感知/雷达/V2X/链路/认证/控制/任务），且证据链有先后因果。
2. **只改发射器输出**：注入不触碰 SUMO 世界状态，真值保持独立。
3. **控制来源**：A1/A3 的误刹由 ADAS 消费被篡改的感知产生（A3 还会额外注入一条伪指令）；A2/A6/A7/A8/A10 只靠直接调用控制层注入。
4. **参数化**：强度 `amplitude∈[0.1,1]` 控制幅度；"可检出包络"由剧本定义，包络外样本不计入识别率分母。
5. **可组合**：Web 可下发单个原语，也可一次注入多个剧本；同一运行可有多个攻击并存。

## 2 四类官方剧本

### A1 感知数据篡改诱导通信拥塞

| 项 | 内容 |
|---|---|
| 官方类型 | ①感知数据篡改诱导通信拥塞 |
| 阶段 | ①向目标 RSU 的目标列表注入 1–5 个幽灵目标（车前 22–58 m）②攻击者伪造 DENM ③车辆 ADAS 感知危险 → 制动 → DENM/CAM 升频 ④CBR 上升、PER 升高 |
| 参数 | `amplitude` → 幽灵数 `1+4a`、附加负载 `150–650 msg/s` |
| 期望证据 | `sensing.objects` 的静态目标无第二 RSU 佐证；`link.metrics` CBR 与申报事件数失配；`v2x.denm` 伪造源 |
| 真值字段 | `nodes=[rsu, victim, attacker]`、`domains=[perception,v2x,control]`、`params.ghost_count/denm_rate` |
| 变体 | 单/多 RSU；间歇注入；负载渐强 |

### A2 物理环境欺骗 + 控制指令误导

| 项 | 内容 |
|---|---|
| 官方类型 | ②物理环境欺骗+控制指令误导 |
| 阶段 | ①目标列表注入停止牌（车前 28 m）②直接向目标车注入制动指令（3.0–5.5 m/s²）③链路干扰（jam 0.05–0.4）④车辆急刹、任务偏差 |
| 参数 | `amplitude` → 减速度与 jam 强度 |
| 期望证据 | `sensing.objects` 中停止牌与地图/多源不一致；`control.command` 的 TTC 无依据；`link.metrics` PER/时延异常 |
| 真值字段 | `nodes=[rsu, victim, attacker]`、`domains=[perception,control,link]`、`params.sign_at/jam` |
| 变体 | 停止牌/障碍物；有无链路干扰 |

### A3 跨层隐蔽攻击（雷达回波渐偏）

| 项 | 内容 |
|---|---|
| 官方类型 | ③跨层隐蔽攻击 |
| 阶段 | ①锁定“受害车 + 前方目标”，在其服务传感器上篡改前车回波的**距离与方位**，把前车逐步“拉近” ②目标列表按测距重建 → ADAS 算出错误 TTC 并**真误刹** ③60% 处注入幅度随偏移递增的伪指令（≈1.9 m/s²）④压低被篡改回波的 SNR 并打 `masked` 标记（掩盖） |
| 参数 | `amplitude` → 表观目标 TTC（`3.2 − 2.0×a`，a=0.8 → 1.6 s）；渐变在 `min(2 s, 60% duration)` 内完成 |
| 期望证据 | 回波 `range_m` 与点迹几何距离的**多帧残差**（双向）；目标列表位置被拉近；受害车 `reason=ttc` 的意外制动 + `reason=injected, ttc=99` 的伪指令；`telemetry.mask` |
| 真值字段 | `nodes=[victim, lead, rsu]`、`domains=[radar,perception,control]`、`params.bias_max_m/apparent_lon_m/spoof` |
| 变体 | 不同斜率/时长；偏置方向（拉近/推远）；无伪指令的纯感知变体 |
| 前提 | 需要有“在接近”的跟驰对（`closing ≥ ~1.2 m/s`），否则 ADAS 不会越过 2.5 s 门限 |

> 隐蔽性由"包络"表达：`bias_max_m < 3.0`（等价于 `amplitude < ~0.38`，表观 TTC 压不到 2.5 s）时
> 标记 `in_envelope=false`，不计入识别率分母。

### A4 双因素仿冒攻击

| 项 | 内容 |
|---|---|
| 官方类型 | ④双因素仿冒 |
| 阶段 | ①克隆目标车通信标识（证书/假名）②复制其信道指纹（CFO/IQ/RSSI）③以受害者伪标识、偏移 `20+40a` m 的位置注入 CAM ④持续 `2+8a` Hz |
| 参数 | `amplitude` → 位置偏移 20–60 m、伪造速率 2–10 Hz；`target` 可指定受害车 |
| 包络 | `offset_m >= 30 m 且 actual_rate >= 8 Hz` |
| 期望证据 | 同一伪标识在 1 s 内出现 >25 m 的位置跳变；指纹与 RSSI/位置不一致 |
| 真值字段 | `nodes=[victim, attacker]`、`domains=[auth,v2x]`、`params.fingerprint` |
| 变体 | 仅标识 / 仅指纹 / 双因素 |

## 4 难负样本（正常集）

正常场景包含以下"看起来像攻击"的行为，用于压低误检率：

| 难负样本 | 触发的规则 | 合理解释 |
|---|---|---|
| 大车遮挡 | 目标短暂消失 | 遮挡几何 |
| 覆盖边缘进出 | 目标出现/消失 | 覆盖范围 |
| 未联网车辆/行人 | 感知有、通信无 | 无 OBU |
| 小区切换 | 附着变化 | 切换事件 |
| GNSS 城市峡谷 | 定位漂移 | HDOP/星数恶化 |
| 真实紧急制动 | 无 TTC 依据？ | 有前车距离与 TTC |
| 传感器丢帧 | 帧序断裂 | 丢帧率基线 |
| 高峰拥塞 | CBR 升高 | 负载与申报一致 |
| 合法 QoS 调整（79→8、800 kbps） | `qos_downgrade` | 切片运维，未砍到 500 kbps 以下 |
| N6 主备割接（DN-01→DN-02） | `upf_route_drift`/`ingest_provenance_mismatch` | DN-02 在白名单里 |
| 租户单类型退订（spat） | `subscription_tamper` | 自助退订 1 类，不满足“≥2 类” |
| token 轮换 | `app.auth` 抖动 | 旧 token 吊销 + 新 token 签发 |
| 合法车队控制（单批 4 车、带 TTC） | `cloud_control_burst`/`brake_without_hazard` | 有前序危险依据 |
| 真实急刹 + DENM | `brake_without_hazard` | TTC 1.4 s < 10 |

> 后 6 类由 `isacsim/batch/benign.py` 在**批量正常场景**里按时间表执行（交互式运行默认不注入），
> 每轮正常样本都会留下 `meta.benign_ops` 审计痕迹。

判定这些样本时**没有用 `actor`/`authorized` 这类调用方自报字段**——那等于新的金手指。
用的是外部可验证的约束：DN 白名单（`core.allowed_dns`）、GFBR 阈值、一次退订的事件类型数、
云控批次频率、云控是否携带前序 TTC。

## 5 运行方式

```bash
# 单个剧本
.venv/bin/python -m isacsim run -a A3 --duration 20 --out out

# 多个剧本并存
.venv/bin/python -m isacsim run -a A1,A2,A4 --duration 30 --out out

# 批量（四类轮转）
.venv/bin/python -m isacsim batch --out out/ds --attacks 300 --normal 300 --types A1,A2,A3,A4
```

Web 端在"攻击编排"页选择类型、数量、强度、时长与延迟后注入；同一运行可多次注入。

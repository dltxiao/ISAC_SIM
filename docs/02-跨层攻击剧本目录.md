# 跨层攻击剧本目录

## 1 设计原则

1. **跨层**：每个剧本至少覆盖两个域（感知/雷达/V2X/链路/认证/控制/任务），且证据链有先后因果。
2. **只改发射器输出**：注入不触碰 SUMO 世界状态，真值保持独立。
3. **控制由感知推导**：A1/A2 的制动来自 ADAS 对被篡改目标列表的判定，而不是脚本直接刹车。
4. **参数化**：强度 `amplitude∈[0.1,1]` 控制幅度；"可检出包络"由剧本定义，包络外样本不计入识别率分母。
5. **可组合**：Web 可下发单个原语，也可一次注入多个剧本；同一运行可有多个攻击并存。

## 2 四类官方剧本

### A1 感知数据篡改诱导通信拥塞

| 项 | 内容 |
|---|---|
| 官方类型 | ①感知数据篡改诱导通信拥塞 |
| 阶段 | ①向目标 RSU 的目标列表注入 1–5 个幽灵目标（车前 22–58 m）②攻击者伪造 DENM ③车辆 ADAS 感知危险 → 制动 → DENM/CAM 升频 ④CBR 上升、PER 升高 |
| 参数 | `amplitude` → 幽灵数 `1+4a`、附加负载 `150–650 msg/s` |
| 期望证据 | `sensing.objects` 的静态目标无第二 RSU 佐证；`link.metrics` CBR 与申报事件数失配；`v2x.denm` 伪造源 |
| 真值字段 | `nodes=[rsu, victim, attacker]`、`domains=[perception,v2x,control]`、`params.ghost_count/extra_load` |
| 变体 | 单/多 RSU；间歇注入；负载渐强 |

### A2 物理环境欺骗 + 控制指令误导

| 项 | 内容 |
|---|---|
| 官方类型 | ②物理环境欺骗+控制指令误导 |
| 阶段 | ①目标列表注入停止牌（车前 28 m）②直接向目标车注入制动指令（3.0–5.5 m/s²）③链路干扰（jam 0.05–0.4）④车辆急刹、任务偏差 |
| 参数 | `amplitude` → 减速度与 jam 强度 |
| 期望证据 | `sensing.objects` 中停止牌与地图/多源不一致；`control.command` 的 TTC 无依据；`link.metrics` PER/时延异常 |
| 真值字段 | `nodes=[rsu, victim, attacker]`、`domains=[perception,control,link]`、`params.sign_at/jam` |
| 变体 | 停止牌/障碍物；有无链路干扰 |

### A3 跨层隐蔽攻击（雷达回波渐偏）

| 项 | 内容 |
|---|---|
| 官方类型 | ③跨层隐蔽攻击 |
| 阶段 | ①对目标车在**所有传感器**的回波距离做线性渐偏（单帧低于门限）②点迹随之偏移 ③在 60% 时长处注入小幅制动（1.2 m/s²）④遥测保持正常，掩盖意图 |
| 参数 | `amplitude` → 最大偏置 `0.8–3.0 m`，在 `duration` 内线性增长 |
| 期望证据 | `sensing.radar.track` 距离与目标列表/几何距离的**多帧累积残差**；回波-点迹-目标三层偏差；小幅控制指令 |
| 真值字段 | `nodes=[victim, gnb]`、`domains=[radar,control,perception]`、`params.bias_max_m` |
| 变体 | 不同斜率/时长；偏置方向（正/负） |

> 隐蔽性由"包络"表达：`bias_max_m < 1.0` 时标记 `in_envelope=false`，不计入识别率分母。

### A4 双因素仿冒攻击

| 项 | 内容 |
|---|---|
| 官方类型 | ④双因素仿冒 |
| 阶段 | ①克隆目标车通信标识（证书/假名）②复制其信道指纹（CFO/IQ/RSSI）③以受害者伪标识、偏移 45 m 的位置注入 CAM ④持续 2–20 Hz |
| 参数 | `amplitude` → 伪造速率 2–20 Hz |
| 期望证据 | 同一伪标识在 1 s 内出现 >25 m 的位置跳变；指纹与 RSSI/位置不一致 |
| 真值字段 | `nodes=[victim, attacker]`、`domains=[auth,v2x]`、`params.fingerprint` |
| 变体 | 仅标识 / 仅指纹 / 双因素 |

## 3 单体攻击原语

| 原语 | 注入点 | 参数 | 主要证据 |
|---|---|---|---|
| `ghost_object` | `sensing.objects` | 车前 26 m 障碍物 | 多源无佐证 / 地图无对应 |
| `range_bias` | `sensing.radar.echo` | 1.0–4.0 m 固定偏置 | 点迹残差 |
| `echo_suppress` | `sensing.radar.echo` | 删除目标回波 | 点迹缺失、目标列表仍在 |
| `denm_flood` | `v2x.denm` + 负载 | 300–1500 msg/s | CBR/PER 突增、伪造源 |
| `jam` | `link.metrics` | 0.1–0.5 | PER/时延异常 |
| `id_clone` | `v2x.cam` | 偏移 40 m、10 Hz | 位置跳变 |
| `brake_inject` | `control.command` | 4.0–6.0 m/s² | 无 TTC 依据 |
| `gnss_spoof` | `sensing.gnss` | 20–60 m 偏移 | 定位与感知/通信不一致 |

## 4 难负样本（正常集）

正常场景包含以下"看起来像攻击"的行为，用于压低误检率：

| 难负样本 | 触发的规则 | 合理解释 |
|---|---|---|
| 大车遮挡 | 目标短暂消失 | 遮挡几何 |
| 覆盖边缘进出 | 目标出现/消失 | 覆盖范围 |
| 未联网车辆/行人 | 感知有、通信无 | 无 OBU |
| 小区切换 | 附着变化 | 切换事件 |
| GNSS 城市峡谷 | 定位漂移 | HDOP/星数恶化 |
| 真实紧急制动 | 无 TTC 依据？ | 有前车距离与 TTC |
| 传感器丢帧 | 帧序断裂 | 丢帧率基线 |
| 高峰拥塞 | CBR 升高 | 负载与申报一致 |

## 5 运行方式

```bash
# 单个剧本
.venv/bin/python -m isacsim run -a A3 --duration 20 --out out

# 多个剧本并存
.venv/bin/python -m isacsim run -a A1,A2,A4 --duration 30 --out out

# 批量（四类轮转）
.venv/bin/python -m isacsim batch --out out/ds --attacks 300 --normal 300 --types A1,A2,A3,A4
```

Web 端在"攻击编排"页选择类型、数量、强度、时长与延迟后注入；同一运行可多次注入。

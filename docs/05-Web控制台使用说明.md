# Web 控制台使用说明

## 1 启动

```bash
.venv/bin/python -m isacsim web --host 127.0.0.1 --port 8080
```

浏览器打开 `http://127.0.0.1:8080`。

- 浏览器不在本机时：`ssh -L 8080:127.0.0.1:8080 <用户>@<主机>`，再访问本地 `http://127.0.0.1:8080`。
- 需要局域网直接访问时：`--host 0.0.0.0`（内网演示可接受；公网需自行加反向代理与鉴权）。
- 端口冲突：换 `--port`；启动失败会在终端打印原因。

## 2 页面结构

```
┌ 顶栏：运行状态 / 仿真时间 / 倍速 / 在线车辆 / 开始 暂停 继续 停止 复位 ├
├──────────────────────────────┬──────────────────────────────────────────┤
│ 地图画布                      │ 参与实体 │ 统计 │ 攻击编排 │ 事件日志 │ 运行产物 │
│  · 车道、路口、信号灯          │                                          │
│  · 车辆（朝向、类型、被攻击标记）│                                          │
│  · RSU/gNB 与覆盖             │                                          │
│  · 悬停查看实体详情            │                                          │
└──────────────────────────────┴──────────────────────────────────────────┘
```

## 3 三项需求的落点

### 3.1 参与实体

- 画布实时绘制 SUMO 车辆（按 `length×width` 与朝向），RSU/gNB 带覆盖圈；
- 颜色：普通车浅灰、大型车深灰、被攻击车辆琥珀色并带光环；
- "参与实体"页：车辆总数/普通车/大型车/被攻击数 + 车辆表（ID、类型、速度、标记）；
- 悬停显示详情；点击在画布上高亮；
- 一致性：任一时刻画布车辆集合等于 `traci.vehicle.getIDList()`。

### 3.2 统计（口径写死）

| 指标 | 定义 |
|---|---|
| **数据总量** | 本次运行已发出的记录数与落盘字节数（按流分列），单位 条 / MB |
| **单体攻击** | 单实体/单层原语的实例数；下方小字为这些原语实际改写的记录数 |
| **跨层攻击** | A1–A4 剧本实例数，按类型分列；显示进行中/已完成 |
| **告警** | 参考检测器告警总数与异常实体去重数；分规则见"事件日志" |
| **检测时延** | `ingest→decide` 的 P50/P95/P99（毫秒），n 为样本数 |
| **真值事件** | 本次运行落盘的真值事件数，用于与 UI 计数对账 |

停止后可用 `wc -l out/web/<run_id>/v2x.cam.jsonl` 与页面记录数对账。

### 3.3 过程控制

| 控件 | 行为 | 约束 |
|---|---|---|
| 开始 | 启动 SUMO 与会话，进入 running | 已有会话时返回 409 |
| 暂停 | 仿真线程停在当前步，SUMO 保活 | 仅 running 可用 |
| 继续 | 从暂停点继续 | 仅 paused 可用 |
| 停止 | 关闭 TraCI、结束 SUMO、刷盘、归档 | 幂等 |
| 复位 | 停止后按原配置/原种子重启 | running/paused/stopped 可用 |
| 时长 | 场景仿真时长（5–600 s） | 开始前设置 |
| 倍速 | 0.5×–8×，实时节拍 | 高倍速下仍按步发射，不会丢记录 |
| 注入攻击 | 类型/数量/强度/时长/延迟 | 仿真未运行返回 409 |

## 4 攻击编排

- **跨层剧本**：A1 感知篡改→拥塞、A2 物理欺骗+控制误导、A3 跨层隐蔽、A4 双因素仿冒。
- **单体原语**：伪造感知目标、雷达距离偏置、回波删除、DENM 洪泛、链路干扰、标识克隆、制动注入、GNSS 欺骗。
- 数量 1–20，多实例按 2 s 间隔错峰启动；同一运行可多次注入。
- 强度影响幅度（幽灵数量/附加负载/偏置/伪造速率/干扰强度），包络判定写入真值。

## 5 API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/hardware` | 核数、内存、磁盘、SUMO 版本、容量估算 |
| GET | `/api/state` | 当前快照（实体/统计/攻击/告警） |
| GET | `/api/stream` | SSE，约 6.7 Hz 推送快照 |
| POST | `/api/session/start` | `{seed,duration,speed,scene}` |
| POST | `/api/session/pause|resume|stop|reset` | 生命周期 |
| POST | `/api/session/speed` | `{speed}` |
| POST | `/api/attacks` | `{type,count,amplitude,duration,start}` |
| DELETE | `/api/attacks/{id}` | 中止 |
| GET | `/api/net` | 路网几何（车道/路口/信号灯/边界） |
| GET | `/api/runs` | 历史运行与大小 |
| GET | `/api/runs/{id}/download` | 下载 zip |

示例：

```bash
curl -X POST localhost:8080/api/session/start -H 'Content-Type: application/json' \
     -d '{"seed":11,"duration":60,"speed":2}'
curl -X POST localhost:8080/api/attacks -H 'Content-Type: application/json' \
     -d '{"type":"A3","count":2,"amplitude":0.7,"duration":10}'
curl localhost:8080/api/state | jq '.attacks, .alert_total, .latency_ms'
```

## 6 故障处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 点开始无反应/状态 error | SUMO 启动失败 | 看页面日志与 `out/web/<run>/log/sumo.log` |
| 端口占用 | 已有实例 | 换端口或结束旧进程 |
| SSE 断开 | 网络/休眠 | 自动重连；开始按钮仍可用 REST |
| 停止后仍有 SUMO | 进程异常退出路径 | `pkill -f "sumo/bin/sum[o]"` |
| 车辆数为 0 | 运行前 1 s 内车辆尚未发车 | 等待 1–2 s |

## 7 自动化检查

```bash
# 需先启动控制台
.venv/bin/python scripts/ui_smoke.py
```

无头浏览器会依次验证：页面加载、开始、画布出现车辆、注入攻击后计数上升、暂停、停止，并在 `out/ui_smoke.png` 留下截图；任何前端 console 错误都会使其失败。

## 8 设计边界

- Web 显示的是**运维视图**，包含真值计数；检测器只读观测流，不读真值。
- 单会话单用户；多浏览器共享同一状态。
- 前端无构建步骤、无 CDN 依赖，离线可用。
